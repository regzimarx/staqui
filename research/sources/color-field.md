# ColorField

Enter a hex color directly or choose it visually.

## Implementation

Six-digit RGB hex only. Alpha, HSL and wide-gamut formats are deliberately excluded. A native color chooser accompanies the editable text input.

## Accessibility

Use a persistent visible label and provide textual errors; native controls support keyboard input and browser form constraints.
