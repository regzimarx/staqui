# ChoiceList

Choose one or several options in a visible list.

## Implementation

Uses fieldset/legend and native radio or checkbox inputs. Values are arrays in both modes. Rich secondary option content is not exposed; option labels are strings.

## Accessibility

Use a persistent visible label and provide textual errors; native controls support keyboard input and browser form constraints.
