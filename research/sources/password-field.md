# PasswordField

Enter a secret with an accessible visibility toggle.

## Implementation

A named, pressed-state visibility toggle preserves focus and value. No password strength scoring or authentication service is included.

## Accessibility

Use a persistent visible label and provide textual errors; native controls support keyboard input and browser form constraints.
