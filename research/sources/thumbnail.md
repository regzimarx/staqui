# Thumbnail

Place a small, consistently sized image beside content.

## Implementation

Native image with small/medium/large dimensions. Alternative text is required. Source failures use native behavior unless an onError handler is provided.

## Accessibility

Preserve semantic structure and communicate meaning with text rather than color alone.
