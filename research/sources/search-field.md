# SearchField

Collect a search query with a recognizable search affordance.

## Implementation

Native type=search with a decorative icon. Filtering is application-owned, as shown in the live example.

## Accessibility

Use a persistent visible label and provide textual errors; native controls support keyboard input and browser form constraints.
