# Number

Format numeric values with locale-aware tabular typography.

## Implementation

Intl.NumberFormat adds locale/currency/percent formatting beyond tabular styling. Numeric formatting is presentation, not decimal arithmetic.

## Accessibility

Preserve semantic structure and communicate meaning with text rather than color alone.
