# Button

Trigger an action with clear hierarchy and immediate feedback.

## Implementation

Three variants, critical tone, three sizes, loading, disabled and fullWidth are supported. Use asChild to compose a navigation link; use callbacks for commands.

## Accessibility

Maintain an understandable accessible name and preserve visible focus for all actions.
