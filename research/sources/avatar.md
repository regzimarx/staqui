# Avatar

Represent a person with an image or a readable initials fallback.

## Implementation

Name supplies accessible text and derived initials. Failed images fall back to initials. No remote avatar service or fabricated profile photographs.

## Accessibility

Preserve semantic structure and communicate meaning with text rather than color alone.
