# Progress

Show how much measurable work has been completed.

## Implementation

Native progress, max defaults to 100, values are clamped. Missing value is indeterminate with a static striped fallback; it does not animate. The indicator uses the brand token rather than per-instance status tones.

## Accessibility

Preserve semantic structure and communicate meaning with text rather than color alone.
