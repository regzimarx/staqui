# Switch

Turn an independent setting on or off.

## Implementation

A native checkbox with role=switch provides Space activation, form participation and checked state. Its visible label describes the setting, not the current state.

## Accessibility

Use a persistent visible label and provide textual errors; native controls support keyboard input and browser form constraints.
