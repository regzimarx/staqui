# URLField

Collect a web address with native URL validation.

## Implementation

Native type=url handles validation and input keyboard. It does not prepend a scheme or rewrite input silently.

## Accessibility

Use a persistent visible label and provide textual errors; native controls support keyboard input and browser form constraints.
