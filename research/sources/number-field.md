# NumberField

Collect a numeric value with step and range constraints.

## Implementation

Native type=number exposes min/max/step and browser steppers. Values emitted by onValueChange remain strings so empty input is representable.

## Accessibility

Use a persistent visible label and provide textual errors; native controls support keyboard input and browser form constraints.
