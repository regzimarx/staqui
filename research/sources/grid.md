# Grid

Arrange content in responsive columns that fit their container.

## Implementation

Responsive auto-fit columns replace GridItem elements and responsive DSL strings. Children can use CSS gridColumn/gridRow. minColumnWidth prevents squeezed content.

## Accessibility

Preserve semantic structure and communicate meaning with text rather than color alone.
