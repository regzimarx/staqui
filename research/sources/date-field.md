# DateField

Enter a calendar date with native format and constraint handling.

## Implementation

Native date input with ISO string values, min/max, required and readOnly. Use DatePicker for calendar matchers and range selection.

## Accessibility

Use a persistent visible label and provide textual errors; native controls support keyboard input and browser form constraints.
