# ButtonGroup

Keep related actions aligned and meaningfully grouped.

## Implementation

Named React children replace primary-action and secondary-actions slots. All actions retain independent tab stops.

## Accessibility

Maintain an understandable accessible name and preserve visible focus for all actions.
