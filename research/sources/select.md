# Select

Choose an option from a native, optionally grouped menu.

## Implementation

Native select/option/optgroup preserve mobile pickers and keyboard behavior. Labels are strings; icon slots are intentionally omitted.

## Accessibility

Use a persistent visible label and provide textual errors; native controls support keyboard input and browser form constraints.
