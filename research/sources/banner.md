# Banner

Bring important feedback and recovery actions into view.

## Implementation

Dismissal is local until remounted; use onDismiss to persist it. Critical banners use alert, other tones use status. React action replaces the secondary-actions slot.

## Accessibility

Preserve semantic structure and communicate meaning with text rather than color alone.
