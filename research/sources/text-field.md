# TextField

Collect a short text value with labels and validation feedback.

## Implementation

Native input attributes with label, description, error, prefix, suffix and onValueChange. Compose accessory actions using React nodes.

## Accessibility

Use a persistent visible label and provide textual errors; native controls support keyboard input and browser form constraints.
