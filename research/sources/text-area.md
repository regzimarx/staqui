# TextArea

Write longer content in a resizable multiline field.

## Implementation

Native textarea with rows, min/maxLength and vertical resizing. Character counting is an application composition, shown in the example.

## Accessibility

Use a persistent visible label and provide textual errors; native controls support keyboard input and browser form constraints.
