# ColorPicker

Choose an RGB color with the native system picker.

## Implementation

Uses the operating-system color interface and six-digit RGB hex. Appearance varies by browser; alpha and an always-visible spectrum are not implemented.

## Accessibility

Use a persistent visible label and provide textual errors; native controls support keyboard input and browser form constraints.
