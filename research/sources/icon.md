# Icon

Use a consistent stroke-based visual language for actions.

## Implementation

A curated Lucide name map with a source prop for custom Lucide icons. Decorative icons are hidden; meaningful icons require a label.

## Accessibility

Preserve semantic structure and communicate meaning with text rather than color alone.
