# Checkbox

Select an independent option or represent partial selection.

## Implementation

Supports controlled/uncontrolled checked state and the native indeterminate property. Required and validation are native browser behavior.

## Accessibility

Use a persistent visible label and provide textual errors; native controls support keyboard input and browser form constraints.
